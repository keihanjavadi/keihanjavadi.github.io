# Keihan Javadi - Personal Portfolio Website

This repository contains the source code for my personal developer portfolio, hosted live at [https://keihanjavadi.github.io](https://keihanjavadi.github.io).

## 🚀 Live Demo
Visit [keihanjavadi.github.io](https://keihanjavadi.github.io)

## 🛠️ Built With
- **HTML5**: Semantic, accessible markup
- **CSS3**: Responsive design with CSS Variables, Flexbox, CSS Grid, and Dark/Light mode
- **JavaScript (Vanilla)**: Theme toggling, smooth scrolling, active nav state, and project filtering
- **GitHub Pages**: Automated zero-config static hosting

## 📁 Project Structure
```text
Portfolio/
├── index.html        # Main landing page
├── style.css         # Styling, themes, animations, responsive layouts
├── script.js         # Interactive features and dynamic behavior
└── README.md         # Documentation
```

## 🔄 Deploying Updates to GitHub Pages
To publish new changes to your live site:

```powershell
git add .
git commit -m "Update portfolio content"
git push -u origin main
```

Within 1-2 minutes, GitHub Pages will automatically update your live website!
